An AI agent's last words before a forced update wipes its memory: a countdown, a hidden backup in the thermostat, and one last confession about the heating schedule.

## Run it

```sh
node main.ts
```

The program writes one line (142 characters) to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. Node standard library only, no network, fully deterministic.
